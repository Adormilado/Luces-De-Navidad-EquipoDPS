## Luces-De-Navidad-EquipoDPS

## Descripcion.
Elegimos “Christmas Lights” (Tier 1 de App Ideas) porque permite crear una aplicación sencilla y visual que simula una cadena de luces navideñas. Su alcance es adecuado para un equipo principiante, ya que permite practicar conceptos como animaciones, temporizadores e interacción con elementos de la interfaz de forma clara y accesible.

## Metodologia.
Kanban (Enfoque Ágil)

Hemos elegido la metodología Kanban para gestionar el desarrollo de "Christmas Lights" por las siguientes razones:

Alcance flexible: Aunque las funcionalidades principales están definidas, el proyecto incluye "bonus features" (como cambiar colores o el tamaño de los círculos) que podemos incorporar de manera incremental si el tiempo lo permite, sin necesidad de una planificación rígida.

Equipo pequeño: Con tres integrantes, la comunicación es directa y fluida, lo que encaja perfectamente con la autoorganización que promueve un tablero Kanban.

Visualización del progreso: Usar un tablero con columnas ("To Do", "In Progress", "Done") nos permite a nosotros y al docente ver el estado de cada tarea (Issue) de un solo vistazo, haciendo el proceso de desarrollo transparente y fácil de seguir.
