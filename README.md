# Luces-De-Navidad-EquipoDPS

## Descripcion.
Elegimos “Luces de Navidad” (Tier 1 de App Ideas) porque permite crear una aplicación sencilla y visual que simula una cadena de luces navideñas. Su alcance es adecuado para un equipo principiante, ya que permite practicar conceptos como animaciones, temporizadores e interacción con elementos de la interfaz de forma clara y accesible.

## User Stories.
- Como usuario, quiero ver una fila de 7 círculos de colores que simulen luces navideñas, para visualizar el efecto de la cadena de luces.

- Como usuario, quiero presionar un botón para iniciar el efecto de "onda" o "parpadeo" en las luces, para ver la animación en acción.

- Como usuario, quiero presionar el mismo botón para detener el efecto en cualquier momento, para pausar la animación cuando lo desee.

- Como usuario, quiero ajustar la velocidad del efecto mediante un control deslizante, para cambiar el intervalo de tiempo entre cada cambio de intensidad de las luces.

## Metodologia.
Kanban (Enfoque Ágil)

Hemos elegido la metodología Kanban para gestionar el desarrollo de "Luces de Navidad" por las siguientes razones:

Alcance flexible: Aunque las funcionalidades principales están definidas, el proyecto incluye "bonus features" (como cambiar colores o el tamaño de los círculos) que podemos incorporar de manera incremental si el tiempo lo permite, sin necesidad de una planificación rígida.

Equipo pequeño: Con tres integrantes, la comunicación es directa y fluida, lo que encaja perfectamente con la autoorganización que promueve un tablero Kanban.

Visualización del progreso: Usar un tablero con columnas ("To Do", "In Progress", "Done") nos permite a nosotros y al docente ver el estado de cada tarea (Issue) de un solo vistazo, haciendo el proceso de desarrollo transparente y fácil de seguir.
